# colombia_plate

Colombia's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the `ABC·123` plate in its private, public-service, official, antique, mototaxi, trailer, tank-truck and diplomatic-staff liveries, the new diplomatic-corps plate and the National Police plate, with their themes, alphabets and advisory validators.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:colombia_plate/colombia_plate.dart';

PlateCanvas(
  spec: ColombiaPlates.privateCar,
  theme: ColombiaThemes.standard,
  validator: const ColombiaValidator(),
  autoValidate: true,
);
```
