# eritrea_plate

Eritrea's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the one plate its article documents: `ER`, a digit in a disc and a five-digit number, black on white, with an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:eritrea_plate/eritrea_plate.dart';

PlateCanvas(
  spec: EritreaPlates.standard,
  theme: EritreaThemes.standard,
  validator: const EritreaValidator(),
  autoValidate: true,
);
```
