# kenya_plate

Kenya's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — three letters, three digits and a letter on one row or stacked, in black on white or yellow, white on green or red, and blue on white, with one theme each and an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:kenya_plate/kenya_plate.dart';

PlateCanvas(
  spec: KenyaPlates.row,
  theme: KenyaThemes.white,
  validator: const KenyaValidator(),
  autoValidate: true,
);
```
