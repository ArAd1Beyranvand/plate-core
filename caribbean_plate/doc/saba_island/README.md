# saba_island_plate

Saba (island)'s licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the 2011 green plate and the 1978 cream plate, one theme each, Latin alphabets, an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:saba_island_plate/saba_island_plate.dart';

PlateCanvas(
  spec: SabaIslandPlates.current,
  theme: SabaIslandThemes.current,
  validator: const SabaIslandValidator(),
  autoValidate: true,
);
```
