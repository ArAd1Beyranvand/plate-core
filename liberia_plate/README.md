# liberia_plate

Liberia's licence plates for [`plate_core`](https://pub.dev/packages/plate_core) — the diplomatic plate (`1 CD 13`), black on a pale field, with one theme, Latin alphabets and an advisory validator.

```dart
import 'package:plate_core/plate_core.dart';
import 'package:liberia_plate/liberia_plate.dart';

PlateCanvas(
  spec: LiberiaPlates.diplomatic,
  theme: LiberiaThemes.diplomatic,
  validator: const LiberiaValidator(),
  autoValidate: true,
);
```
