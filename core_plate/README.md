## Migration Guide

Simply replace your dependency:

**Old (deprecated):**
```yaml
dependencies:
  core_plate: ^0.0.1
```

**New (correct):**
```yaml
dependencies:
  plate_core: ^0.12.0
```

Then update your imports from:
```dart
import 'package:core_plate/core_plate.dart';
```

to:
```dart
import 'package:plate_core/plate_core.dart';
```

All functionality is identical. [`plate_core`](https://pub.dev/packages/plate_core) is the official package.
