# venezuela_plate

Venezuela's licence plate for the plate_core library — the 2008 car plate with the flag background, the state-code alphabets and the advisory category validator.

## Quick start

### Install (Kotlin)

Copy `kotlin/src/commonMain/kotlin/plates/countries/venezuela/` into `plate_core/kotlin/src/commonMain/kotlin/plates/countries/`.

Then run the tests from `plate_core/kotlin/`: `./gradlew jvmTest`.

### Use

```kotlin
import plates.countries.venezuela.country

val spec = country.specs["ve.car"]
println(country.pkg)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ve.car`

## Themes

- `VenezuelaPlates.theme`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`VenezuelaValidator`).
