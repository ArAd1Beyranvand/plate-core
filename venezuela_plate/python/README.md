## Quick start

### Install (Python)

Copy `python/plates/countries/venezuela/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.venezuela.data import SPECS, THEMES

spec = SPECS["ve.car"]
theme = THEMES["VenezuelaPlates.theme"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ve.car`

## Themes

- `VenezuelaPlates.theme`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `VenezuelaValidator` to classes.
