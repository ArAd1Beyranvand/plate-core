## Quick start

### Install (Python)

Copy `python/plates/countries/mali/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.mali.data import SPECS, THEMES

spec = SPECS["ml.standard"]
theme = THEMES["MaliThemes.standard"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ml.standard`

## Themes

- `MaliThemes.standard`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `MaliValidator` to classes.
