## Quick start

### Install (Kotlin)

Copy `kotlin/src/commonMain/kotlin/plates/countries/mali/` into `plate_core/kotlin/src/commonMain/kotlin/plates/countries/`.

Then run the tests from `plate_core/kotlin/`: `./gradlew jvmTest`.

### Use

```kotlin
import plates.countries.mali.country

val spec = country.specs["ml.standard"]
println(country.pkg)
```

## Specs

The specs are the same in every language (they come from shared data).

- `ml.standard`

## Themes

- `MaliThemes.standard`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`MaliValidator`).
