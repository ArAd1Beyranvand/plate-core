# yemen_plate

Yemen's licence plates for the plate_core library — the 2026 unified specs, the 1993 northern specs, the alphabets, the usage themes and the advisory validators.

## Quick start

### Install

```yaml
dependencies:
  plate_core: ^0.12.0
  yemen_plate: ^0.3.0
```

### Use

```dart
import 'package:plate_core/plate_core.dart';
import 'package:yemen_plate/yemen_plate.dart';

PlateCanvas(
  spec: YemenNorthernPlates.car,
  validator: const YemenNorthernValidator(),
  autoValidate: true,
  onChooseCharacter: noCharacterChooser,
);
```
