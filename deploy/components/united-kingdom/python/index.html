United Kingdom license plates in Python

The library draws 17 plate formats for United Kingdom, among them Rear (yellow), Front (white), Rear with UK band and Zero-emission rear. The region or district on a plate is looked up from its code and shown beside the number. A typical registration reads BD51SMR. This page runs the Python port on Pyodide: type a registration and watch the plate take shape and get checked as you go.
