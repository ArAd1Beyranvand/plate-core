Namibia license plates in Python

The library draws 10 plate formats for Namibia, among them Windhoek, six digits, Six digits, two-letter town, Five digits and Four digits, two-letter town. The region or district on a plate is looked up from its code and shown beside the number. A typical registration reads 108053W. This page runs the Python port on Pyodide: type a registration and watch the plate take shape and get checked as you go.
