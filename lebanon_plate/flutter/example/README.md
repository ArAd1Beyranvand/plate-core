# lebanon_plate example

One `PlateCanvas` drawing `LebanonPlates.oneLine`, with the band caption and the
field colour both derived from a `LebanonUsage`. Change `usage` in
`lib/main.dart` to `LebanonUsage.diplomatic` to see the same plate on an orange
field, or swap `oneLine` for `twoLine` to see the other geometry.

```sh
flutter run
```
